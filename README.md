# RedotPay Virtual Card Guide — دليل ريدوت باي

Independent static bilingual (Arabic/English) tutorial directory for the YouTube channel **Majd Fatihy / ماجد فتحي**.

## Files

- `index.html`: Arabic version, automatically offers the English version for English-language browsers.
- `en/index.html`: English version, manually accessible and indexable by crawlers.
- `assets/style.css`: responsive, print-ready page styling.
- `assets/app.js`: client-side search, categories, accessible video modal, language choice and referral-code copy.
- `assets/og-redotpay.png`: 1200 × 630 social preview image.
- `research/videos.json`: 11 curated, directly relevant RedotPay videos, their dates and dated summaries.
- `research/video-notes.md`: extracted learning notes from YouTube captions, not misrepresented as current company policy.
- `research/sources.md`: verified RedotPay help-center sources.

There is deliberately **no `robots.txt` or `sitemap.xml`**. These belong to the canonical parent site, [dev.majdfatihy.com](https://dev.majdfatihy.com/). Legal/about/contact pages are also linked to the parent site rather than duplicated here.
